# Lamun

Lamun is a planned native macOS Menu Bar audio mixer and audio-focus manager. The intended product offers independent application volume control and optional local Smart Ducking. **Neither audio feature is implemented yet.** The current project is in Phase -1 Engineering Preparation.

Start with [Project Status](docs/PROJECT-STATUS.md), [Project Rules](docs/PROJECT-RULES.md), and the [Development Plan](docs/PLAN.md). The complete product and engineering specification is [PROMPT.md](docs/PROMPT.md).

For setup and commands, see [Development](docs/DEVELOPMENT.md). For current architecture, security, and tests, see [Architecture](docs/ARCHITECTURE.md), [Security](docs/SECURITY.md), and [Testing](docs/TESTING.md).
